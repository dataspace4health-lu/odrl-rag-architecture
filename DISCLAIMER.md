# Disclaimer

This repository is a sanitised architecture and validation case study.

Dataset cards, test scenarios, policy templates and guidance restatements are
synthetic. The operand vocabulary contains sanitised semantic facts extracted
from DS4H implementation documentation: operand names, observed values,
namespaces and a deployment baseline. The corpus labels the provenance of each
document.

It does not contain source implementation documents, production credentials,
service endpoints, infrastructure configuration, verifiable credentials, signed
tokens, patient data, or live integration details.

It is not a deployed application, a production integration, or runnable
software. Nothing here should be treated as a working policy engine, or as legal
or compliance guidance.

Any organisation named inside an execution record appears only in a synthetic
test scenario constructed to test refusal behaviour. It does not describe a real
access request, approval or data transfer.
