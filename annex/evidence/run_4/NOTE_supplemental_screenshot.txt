FIGURES IN THE SCREENSHOT DO NOT ALL MATCH metrics.txt
------------------------------------------------------
This is expected and is recorded rather than reconciled.

                    original run          supplemental re-execution
ChatGPT 4o          1679 tok $0.002579    1679 tok $0.002579   identical
Claude 4.6 Sonnet   1067 tok $0.004737    1057 tok $0.004587   differs

GPT-4o reproduced byte-identically a day apart at temperature 0.1. Claude
produced the same status, the same empty policy and the same four clarification
items, but reworded them, changing character and token counts.

This is a second instance of the behaviour first observed between Runs 1A and
1B, where Claude was run twice at identical settings: structural and grounding
decisions were stable, free-text strings were not. It supports the design
conclusion that validation must key on structured fields rather than on text
matching.

The supplemental outputs are stored alongside the originals as
output_*_supplemental_rerun.txt and metrics_supplemental_rerun.txt. They are
additional evidence, not a substitute for the experiment record, and the
Validation Report is unchanged.
