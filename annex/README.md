# Annex

Supporting material for the case study. Read the root README and FINDINGS first.

| Folder | Contents |
|---|---|
| `corpus/` | The retrieval corpus: 43 indexed rules across five guidance documents, always-on refusal rules, four synthetic dataset cards, one adversarial fixture. Synthetic and public-derived guidance plus sanitised DS4H semantic facts |
| `prompts/` | The complete single field input executed for each run |
| `evidence/` | Raw model outputs, platform metrics and screenshots, one folder per run |

Prompt versions, failed outputs and truncated responses are preserved as
produced. The only publication edit is the documented Run 6 organisation name
redaction.
